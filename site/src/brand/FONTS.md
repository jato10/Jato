# Type sources for the brand mark

`make-logo.mjs` converts glyphs into raw SVG path data, so the published logo
files carry no font dependency at all. The two faces below are only build-time
inputs.

| File | Family | Weight | Used for | License |
| --- | --- | --- | --- | --- |
| `pf.ttf` | Playfair Display | 700 | the `GB` monogram | SIL Open Font License 1.1 |
| `jost4.ttf` | Jost | 300 | the `GLOBAL BEYOND LLC` wordmark | SIL Open Font License 1.1 |

Both families are published by Google Fonts under the OFL, which permits
redistribution and use in derived artwork such as a logotype.
