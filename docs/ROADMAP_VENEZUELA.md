# Jato SuperApp: Roadmap de Producto y Backlog de Funcionalidades (Venezuela)

Este documento sirve como el **backlog maestro y hoja de ruta tecnológica** para el despliegue progresivo de Jato SuperApp en el mercado venezolano.

---

## 🗺️ Fase 1: Lanzamiento MVP & Núcleo Operativo (Caracas, Valencia, Maracaibo)

### 1.1. Movilidad y Logística
- [x] **Jato Express**: Servicio de traslado individual urbano en sedanes/compactos con AC.
- [x] **Jato Moto**: Traslados rápidos en motocicleta para evadir congestiones de tráfico.
- [x] **Jato Delivery**: Envíos puerta a puerta de encomiendas ligeras y comida con seguimiento GPS en tiempo real.
- [x] **PIN de Seguridad de Abordaje**: Confirmación obligatoria de 4 dígitos antes de iniciar el viaje.

### 1.2. Seguridad Cibernética y Física
- [x] **Zero-Trust Security**: Firma de payloads HMAC-SHA256 y encriptación AES-256-GCM para cédulas y datos financieros.
- [x] **Hardware Anti-GPS Spoofing**: Verificación multinivel de ubicación combinando celdas de telefonía, Wi-Fi y acelerómetro.
- [x] **Botón de Pánico Inteligente SOS (Jato Shield)**: Alerta instantánea al Centro de Control de Seguridad con transmisión de audio.
- [x] **KYC Biométrico Facial**: Registro de conductores con prueba de vida 3D y verificación aleatoria durante la jornada.

### 1.3. Ecosistema de Pagos Venezolano
- [x] **Pago Móvil C2P Automatizado**: Débito directo instantáneo con clave SMS bancaria.
- [x] **Suscripción Fija Mensual**: $35 USD para Motos / $45 USD para Autos.
- [x] **Recargo Tecnológico Condicional**: $0.35 USD cobrado en pagos electrónicos y exento en pagos en efectivo.
- [x] **Binance Pay (USDT) & Zelle**: Integración multimoneda sin comisiones para transferencias.
- [x] **Billetera Interna (Jato Pay)**: Acreditación automática del vuelto en efectivo.

---

## 🚀 Fase 2: Expansión Regional y RegTech Avanzado (v1.5)

### 2.1. Funcionalidades de Usuario y Conductor
- [ ] **Modo "Viaje Compartido / Pool"**: Rutas optimizadas en horas pico con división automática de tarifa entre pasajeros.
- [ ] **Jato Mujer**: Opción para que conductoras femeninas atiendan solicitudes exclusivamente de pasajeras mujeres.
- [ ] **Programación de Viajes**: Reserva de traslados al aeropuerto (Maiquetía, Arturo Michelena, La Chinita) con hasta 7 días de anticipación.
- [ ] **Billetera Jato Pay P2P**: Transferencia instantánea de saldo entre usuarios de Jato Pay usando número telefónico.

### 2.2. Cumplimiento Regulatorio y RegTech Automático
- [ ] **Validación API con INTT**: Integración en tiempo real para verificar estatus de licencias de conducir y títulos RNV.
- [ ] **Consulta Automática de Pólizas RCV**: Cruzado de póliza de seguro contra servidores de SUDEASEG.
- [ ] **Emisión Automática de Factura Digital SENIAT**: Integración con imprentas digitales autorizadas para enviar facturas electrónicas con código QR.

---

## 🏢 Fase 3: Corporativo, Carga Pesada e Inteligencia de Negocios (v2.0)

### 3.1. Jato Business (Cuentas Corporativas)
- [ ] **Portal de Gestión de Flotas Empresariales**: Centro de control para empresas con facturación consolidada a fin de mes.
- [ ] **Límites de Presupuesto y Horarios**: Control de viajes para empleados restringidos a rutas de oficina.

### 3.2. Jato Cargo & Logística de Distribución
- [ ] **Carga Pesada y Mudanzas**: Solicitud de camiones (350, 750, plataformas) para comercios e industrias.
- [ ] **Enrutamiento Multiparada**: Optimización de rutas de distribución para comercios minoristas y e-commerce.

### 3.3. Inteligencia Artificial y Eficiencia Energética
- [ ] **Ajuste Dinámico de Tarifa por Tráfico (AI Predictive Price)**: Modelo predictivo impulsado por machine learning para prever congestiones en vías principales (Autopista Gran Mariscal de Ayacucho, Prados del Este, etc.).
- [ ] **Mapas Desconectados Resilientes (Offline Routing)**: Navegación continua en zonas con baja cobertura de señal 4G/LTE mediante mapas vectoriales cacheados en el dispositivo.
